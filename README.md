 Anti-nemotrix
Lightweight open-source tool to remove and block Nemotrix adware infections from Windows systems.

 Anti-Nemotrix Guard

RU:
Утилита для очистки системы от рекламного ПО Nemotrix. Скрипт блокирует вредоносные домены, удаляет записи в реестре и очищает временные файлы.

Возможности:
1. Блокировка доменов через файл hosts для предотвращения редиректов.
2. Удаление ключей автозагрузки в реестре.
3. Очистка временных файлов вируса.
4. Сброс кэша DNS.

Инструкция:
1. Скачайте AntiNemotrix.bat.
2. Запустите от имени администратора.

EN:
Utility to clean the system from Nemotrix adware. The script blocks malicious domains, removes registry entries, and clears temporary files.

Features:
1. Domain blocking via hosts file to prevent redirects.
2. Removal of startup keys in the registry.
3. Cleanup of temporary adware files.
4. DNS cache flush.

Instructions:
1. Download AntiNemotrix.bat.
2. Run as Administrator.
